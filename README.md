
# React Portfolio Platform

A responsive portfolio website built with React and Vite. It allows visitors to explore projects, search through the portfolio, and learn more about the developer.

## Features

- Responsive navigation bar
- Hero section
- Project cards
- Project search functionality
- Add new projects dynamically
- About Me section
- Developer skills section
- Responsive design

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Git and GitHub

## Installation

Clone the repository:

```bash
git clone git@github.com:blairmacharia28-cpu/React-Portfolio-Platform.git
```

Navigate into the project:

```bash
cd React-Portfolio-Platform
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
